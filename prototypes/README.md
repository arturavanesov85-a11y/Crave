# Прототипы CRAVE

Кликабельные макеты на чистом HTML/CSS/JS, без сборки и зависимостей.

## Запуск

```bash
npm run proto
```

Откройте http://localhost:4173. Можно и без сервера — двойным щелчком по `index.html`.

## Что внутри

| Файл | Экран | Что можно проверить |
|---|---|---|
| `home.html` | Главная проката | Выбор дат на первом экране, мобильное меню, переход в каталог с датами |
| `catalog.html` | Автопарк | Срок аренды, фильтры, итог за период, залог отдельно |
| `car.html?car=<slug>` | Карточка машины (мобильная) | Калькулятор, «Все тарифы», водитель, отправка заявки |
| `crm-calendar.html` | Календарь CRM | День / неделя / месяц, создание брони с проверкой пересечений и буфера |
| `crm-order.html` | Карточка заказа | Вкладки, приём оплаты и залога, начисления, скидка с причиной, история |

## Оговорки

- Тарифы взяты с текущего сайта (`assets/data.js`) и ещё не подтверждены владельцем.
- Сутки считаются блоками по 24 часа, весь срок оплачивается по ставке своей ступени. Оба правила — предположения (вопросы A2 и A3 в `docs/01-missing-data.md`).
- Брони, клиенты и сотрудники в CRM — демо-данные. Данные хранятся только в памяти страницы и сбрасываются при перезагрузке.
- Фото автомобилей заменены светлыми заглушками в стандарте будущей съёмки.
